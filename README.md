 GestãoMood WEB

  * Sobre o projeto:

O GestãoMood é um sistema de gerenciamento para uma loja, desenvolvido originalmente como uma aplicação desktop.

Nesta etapa, o projeto foi reorganizado e refatorado com o objetivo de separar melhor as responsabilidades das classes, facilitar a manutenção do código e preparar a estrutura para uma futura versão web.

  * Objetivos da refatoração:

- Aplicar princípios de SOLID para melhor adesão ao web;
- Separar modelos, acesso ao banco de dados e regras de negócio;
- Reduzir responsabilidades excessivas nas classes;
- Organizar o acesso ao banco de dados através de DAOs;
